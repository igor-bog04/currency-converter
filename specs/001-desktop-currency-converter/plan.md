# Implementation Plan: Desktop Currency Converter

**Branch**: `specs` | **Date**: 2026-11-04 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification and implementation constraints supplied by the user.

## Summary

Deliver a Windows desktop currency converter that uses official BNM rates, performs Decimal-based
cross-currency calculations, and remains responsive during network activity. The app will use
CustomTkinter for its Russian-language light/dark interface, a layered set of rate source, cache,
provider, conversion, validation, and UI modules, and `main.py` as the composition root. Layers
communicate through small typed interfaces, with concrete classes wired in `main.py`. The latest
validated BNM snapshot will be stored atomically in the user's AppData directory.

## Technical Context

**Language/Version**: Python 3.11+

**Primary Dependencies**: CustomTkinter for UI; requests for HTTP; pytest for tests. XML parsing,
Decimal arithmetic, threading, JSON, and atomic replacement use the Python standard library.

**Storage**: One JSON cache at `%APPDATA%\CurrencyConverter\cache.json`, containing the last
successfully validated BNM rate snapshot and its effective date.

**Testing**: `python -m pytest`; unit tests cover all non-UI logic and mock HTTP requests.

**Target Platform**: Windows desktop; cache location follows the user's Windows AppData directory.

**Project Type**: Desktop application.

**Performance Goals**: A conversion completes within 10 seconds when one BNM request succeeds over
a normal internet connection; the target excludes date fallback. Each HTTP attempt times out after
10 seconds. Network work and date fallback run off the UI thread. During fallback, a loading
indicator remains visible and the UI stays responsive.

**Constraints**: Rates and amounts use Decimal only; conversion output is rounded to 2 decimal
places and displayed rates to 4. Search the selected date and then up to 10 preceding calendar
dates. Amount input consists of digits with at most one comma or dot decimal separator and at most
2 fractional digits; reject grouping separators, scientific notation, multiple separators, and
other invalid input. Persist cache updates atomically. UI content is Russian; documentation is
English.

**Scale/Scope**: Single-user desktop app, one visible conversion workflow, and one last-successful
rate snapshot in the local cache; no accounts or server-side synchronization.

**Structure Decision**: Use one importable `currency_converter` package for the isolated layers,
with narrow typed interfaces between source, cache, provider, and UI, and root `main.py` as the sole
composition root. Place pytest unit tests in `tests/unit/`; there is no separate backend, service
process, or public application API.
